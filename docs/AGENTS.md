## Documentation Guidelines
### Minimal documents
Documents cover their task in a way that cannot be reduced further: removing any part of minimal document would materially change outcome: for implementation documents, the implementation would come out different
## Content Flow
Progressive refinement: the content of the document should flow from higher-level to lower-level; you can only reference concepts defined earlier in the document.

Coherence: adjacent sections should mostly be at the same level of abstraction, as contrasted to progressively refining one concept to the lowest level, and then continuing up to the next concept.
